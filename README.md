# Vitta

Doctor and appointment management application by David Antass, built with Java 21, Spring Boot, Spring Security, Thymeleaf, MySQL 8.4 and Flyway.

Repository: [DaviDantass/vitta](https://github.com/DaviDantass/vitta)

## Run locally

Requirements: Java 21 and Docker Compose. The Maven wrapper downloads Maven automatically.

```bash
docker compose up -d --wait
./mvnw spring-boot:run
```

Open http://localhost:8080. Database migrations run automatically at startup.

The local database is `vitta`, with user `vitta`, password `vitta_local`, and Docker volume `vitta_mysql_data`. These defaults are for local development. Override `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, and `MYSQL_ROOT_PASSWORD` through environment variables as needed. A Compose `.env` file configures Docker; export matching variables when running the application separately.

Authentication reads accounts from the `users` table. A fresh database has no accounts. Insert a user with a BCrypt password hash generated by Spring Security's `BCryptPasswordEncoder`; plain text passwords do not work.

## Verify

```bash
./mvnw verify
```

Patient management is available at `/patients`. Appointments select registered patients and store foreign keys to both doctors and patients.

Database integration tests run only when `VITTA_TEST_DB_URL` points to a dedicated test database. The default test command runs service and MVC tests without accessing MySQL.

```bash
VITTA_TEST_DB_URL=jdbc:mysql://localhost:3306/vitta_test ./mvnw verify
```

For databases containing legacy appointments, register patients with matching CPFs after V4 and before V5. V5 stops if an appointment cannot be matched and preserves the original patient text. On MySQL, a failed attempt may leave the nullable `patient_id` column: correct the legacy data, remove that added column and repair the failed Flyway history entry before retrying.

## Reset local data

```bash
docker compose down --volumes
docker compose up -d --wait
```

This deletes all local database data. Restart the application to recreate the tables through Flyway.
